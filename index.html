💾 Website Downloaderr

Download the complete source code of any website — HTML, CSS, JavaScript and images — as a ZIP file. Free and open source.

Note: this page is an information page only. Website Downloaderr is a Node.js server app — it runs on your own machine or server, not in this static page. Follow the steps below to run it.

How it works

Paste a website address, and the tool mirrors the site with wget (--mirror --convert-links --adjust-extension --page-requisites --no-parent), compresses everything into a ZIP with archiver, and sends it back to you over a live socket connection. Links are converted to relative paths so the downloaded copy works offline.

Run it yourself

git clone https://github.com/mrabr381/website-downloaderr.git
cd website-downloaderr
npm install
npm start

Then open http://localhost:3000/ in your browser.

Requirements

  • Node.js 16 or newer
  • wget on your PATH (Debian/Ubuntu: apt install wget · macOS: brew install wget · Windows: winget install JernejSimoncic.Wget)

Optional settings

VariableDefaultWhat it does
PORT3000Port the server listens on
DOWNLOAD_QUOTA500mSize ceiling passed to wget, so one request cannot fill the disk
DOWNLOAD_TIMEOUT_MS1800000How long a single download may run before it is stopped

Deploy it

This is a Node.js server, so it needs a host that runs Node — for example Render, Railway or Koyeb (deploy buttons are in the README). Static hosts such as GitHub Pages cannot run it.
